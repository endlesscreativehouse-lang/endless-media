# endless-media

Public image host for @endlesskuwait Instagram publishing.

Meta's Content Publishing API downloads each image from a public URL at post time,
so these JPEGs must stay public and the paths must stay stable.

Base URL: `https://raw.githubusercontent.com/endlesscreativehouse-lang/endless-media/main/media`

Images only. No tokens, no `.env`, no `posted.json`.
